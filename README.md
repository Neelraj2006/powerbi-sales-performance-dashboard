# Power BI Sales Performance Dashboard

## Project Overview
An interactive e-commerce sales dashboard built using Power BI to explore revenue, order volume, product performance and city-level sales.

This is a learning project based on fictional sample data.

## Tools Used
- Power BI Desktop
- Power Query
- DAX (Data Analysis Expressions)
- Excel

## Data Preparation
- Removed duplicate transactions.
- Standardised text values and corrected data types.
- Handled missing values using documented assumptions.
- Created relationships between Customers, Products and Orders.

## Dashboard Features
- Total Revenue
- Total Orders
- Average Order Value
- Electronics Revenue
- Revenue by City
- Revenue by Category
- Revenue by Product
- Interactive City and Category slicers

## Key Findings
- Total revenue: ₹381,700
- Total orders: 15
- Electronics revenue: ₹315,700
- Highest-revenue city: Mumbai, at ₹216,200
- Highest-revenue product: Laptop, at ₹250,000

## Files
- `Ecommerce_Sales_Performance.pbix` — Power BI report
- `dashboard-screenshot.png` — Dashboard preview

## Limitations
The report uses a small fictional dataset. The findings are illustrative and should not be treated as real company performance.
